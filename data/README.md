# 资料口径

金额为币种的基本货币单位，以十进制字符串表示。正值为流入，负值为流出。应付、保证金在当日的预计入金前扣留；已收款若超过分析窗起点，按可见到账日期计入，窗前余额由授信余额承接。授信按主体和币种使用，bridge_to 若非空只允许从该主体调出人民币，按银行经营周滞后到账；bridge_max_cny 是单周可转上限。
合约记有方向为卖出外币买人民币的远期，margin_cny 为常态预留，场景倍数可提高占用，交割并收到凭据后释放。合同额度按尚未交割名义额消耗。拆期由一组 replacement 完整替代同一 flow 的原预测。情景权重用于比较，历史回测以实收而不是假设回款为准。
